# 忍3助手 · Ninja3 Assistant

面向 Windows / MuMu 的《忍者必须死3》实验自动化助手。WinUI 界面、Python 任务规划与视觉处理、C++ 多手指输入，共用可撤回的实时战斗内核。

**当前为源码发布。** 游戏识别素材、模型权重、录像及账号数据不随仓库提供；运行完整游戏任务前，需要自行准备有权使用的本地资源。项目非官方，与游戏或模拟器厂商无关联。

## 主要功能

### 多任务自动规划

可以同时勾选多个清理项目和活动。助手先处理每日清理，再完成各活动日常，最后执行打满场次或持续对战。每个任务有自己的运行逻辑，Plan 管理进度、优先级、开放时段和重试，调度器按优先级串行执行。

任务异常保留未完成状态，安排重试并继续其他可执行任务。对局尚未结束时优先恢复当前对局。开启悬赏的自动接受选项后，助手会在安全间隙处理好友或族员发来的所选等级邀请。

### 每日清理

常规十五项默认勾选。「好友饭团领取与赠送」可单独开启。打开「每日清理」后运行已勾选的项目。

| 项目 | 自动处理 |
| --- | --- |
| 每月日签到 | 检查当前签到进度、滚动领取，最多25天 |
| 好友饭团领取与赠送 | 优先批量回赠，再领取饭团和补赠好友。助手每天最多赠送15个，额度在北京时间05:00刷新，重启后保留当天记录 |
| 限时签到 | 检查当前十日签到和三千日答谢礼 |
| 家族免费祈福 | 领取明确标为免费的次数，已使用后跳过 |
| 免费武器抽取 | 检查白银武库的免费次数及冷却状态 |
| 免费咒印抽取 | 从金匙宝库进入咒印炼化，只操作免费次数 |
| 悬赏商店 | 使用忍币购买每日D级、C级悬赏奖册 |
| 每日商店 | 购买当前忍币商品，不付费刷新 |
| 小屋修炼 | 领取碎片，消耗5饭团沿用原角色继续修炼 |
| 每日悬赏 | 用滑块选择D、C、B、A中的单一等级，处理每日3次和1次免费购买次数 |
| S级悬赏 | 独立清理当前累计奖励次数，最多7次，不受普通等级滑块影响 |
| 忍村试炼 | 从右侧已通关关卡开始，向左检查并扫荡 |
| 忍阶奖励 | 领取已完成的每日任务奖励和每周随机道具，不自动前往未完成任务 |
| 通灵兽每日喂养 | 收取已完成的巡逻奖励，按所选路线喂养，可选经验、忍币或强化锤，默认经验 |
| 竞技场奖励领取 | 检查并领取可领的竞技场奖励 |
| 老板娘答题 | 优先使用实机确认的答案，其次使用导入的基准题库。新题随机选择，继续记录正误并排除已知错误选项 |

助手按实例保存小屋修炼倒计时。到时后在当前任务的下一个安全检查点获得最高优先级。扫荡前按**每30分钟恢复1饭团**计算续练预留，倒计时未知时预留5点。饭团不足时保留未完成状态。

免费操作会在执行前重新检查按钮中的免费标签，结果页只确认奖励；商店购买需确认忍币图标。限时签到入口随活动轮换需要更新，未确认的页面和自选奖励不会自动当作完成。

识别忍阶任务页和忍阶预览页，其他任务误入后返回主页，避免卡住。忍阶任务同时领取每日奖励与每周随机道具，不领取主线奖励。

主页与召唤页入口跟随账号已解锁功能定位，处理首次进入的说明页、家族入场展示及奖励遮挡。日常完成状态保存在当前 Worker 的内存中，按北京时间 05:00 刷新。同一等待状态持续 12 秒仍无进展时保存画面。确认在主页但找不到限时签到入口，或在对应页面仍无法确认试炼饭团或次数、竞技场领奖入口、答题题干或选项时，今天暂缓该项并保留未完成状态。其他等待按原计划重试。

每日悬赏支持加入对应等级的队伍或自己建队。同时选择 A 级和 S 级时，先打完 A 级次数，再处理 S 级。S 级没有队伍和自有召令时，持续刷新列表并优先加入确认的 S 级队伍。「主动邀请好友、族员」和「自动接受好友、族员邀请」可以分别勾选，也可以同时开启。两项默认开启，适用于普通和 S 级悬赏。主动邀请在自建队伍缺队友时发送，自动接受按所选等级和安全间隙处理。结算后重新检查剩余次数和悬赏每日任务，领取好友组队、家族组队的任务奖励，任务状态不明时保留未完成。战斗使用共用实时内核：地面滑步收集忍币，绳索上取消移动；Boss头像出现即释放忍术，血条作为补充信号，并用独立手指持续使用左右武器技能。悬赏的队伍流程和战斗动作验证范围另见下方验证状态。

### 情报模拟战

- 在任务中心的「限时活动」中切换「情报模拟战」和「须弥幻境」。两项可分别开启。
- 自动进入活动、滚动检查三项日常进度、领取奖励、购牌、准备和处理结算。可选择完成日常后停止，或继续对战。
- 根据当前金币、空位和卡库信息规划多卡组合、购买顺序及站位，考虑已支持的属性、职业、相邻和行列联动。
- 将回合收入、额外刷新、留金币与空位的后续机会、剩余金币伤害和鬼斩特殊胜利条件纳入估算；购牌后按新画面校验并续接原组合，棋盘、商店或金币变化时重新规划。
- 日志显示选择理由、预算、组合及联动收益。空卡背和选中加号兼容不同渲染；未知卡保留占位，保存本地整帧、裁剪和识别候选，便于后续补充识别。

选卡使用有界搜索和效果估算，不保证全局最优，也不等同于胜率预测。具体支持范围见[选牌策略说明](docs/ARCHITECTURE.md#情报模拟战选牌)。

### 须弥幻境

在任务页开启限时活动「须弥幻境」前，先手动配好方寸和大千各自的两支队伍，并为大千队伍装备武器。助手从游戏当前开放的第一重或第二重开战，每轮依次打两个 Boss，结算后复查进度并领取可领的奖励。缺队伍或武器时跳过对应试炼，四项奖励均确认领取后结束当日日常。

### 周末多人竞速

在任务中心的「周末活动」中开启多人竞速。支持完成每日任务后停止，或完成每日最多25场积分比赛。进入前确认当前玩法为多人竞速；当前活动先显示介绍页，需经「前往活动」进入排行榜主页，活动轮换后不直接进入其他玩法。

当前日常为五项：参加1场、参加4场、累计4000米、累计10000米和获得一届第一名。助手在每局结算后检查任务页，通过「一键领取」收取可领奖励，再确认任务币奖励弹窗。主页不再显示旧版剩余积分场次文字，打满模式按已确认结算的当日场次计数，到达25场后停止。

基础移动采用“两次起跳 → 下滑”循环，正向识别前方障碍并释放获取的道具卡。绳索上跳跃前进，识别到上方地板时尝试登板，离绳后接回地面循环。

### 自动战斗与调试

活动和自动战斗共用实时处理内核：管理画面时效、识别节奏、多手指指令和取消。连续移动计划最长3秒，后续画面可续接、修改或撤回；移动、应急动作、武器和卡牌可分配不同手指，暂停、停止或退出场景时释放输入。

提供隼白战斗流程、训练所诊断、仅观察的场景调试，以及离线视频播放、逐帧分析。WinUI 任务页顶部固定启动、暂停和停止按钮；设备页可选择是否在运行时隐藏游戏窗口。

助手最小化后留在系统托盘，后台任务继续运行。点击关闭会询问是否进入托盘或退出，默认选择进入托盘，可记住选择；设备设置中可恢复每次询问。双击托盘图标恢复窗口，右键可显示主窗口或退出助手，真正退出时停止运行组件并释放输入。

## 开发与构建

需要 Windows、Python 3.12、Visual Studio C++ Build Tools、Windows SDK 和支持项目目标框架的 .NET SDK。WinUI 依赖版本以 `winui/Ninja3Assistant.csproj` 为准。

GPU 推理通过 Windows ML 加载系统已安装的 TensorRT RTX 执行提供程序。升级开发环境时请新建虚拟环境，旧的 `onnxruntime-directml` 和当前的 `onnxruntime` 共用 Python 导入路径。

```powershell
git clone https://github.com/tanwenhai/ninja3-assistant.git
cd ninja3-assistant
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pip install -e .
python -m tools.testing.run_portable_tests
```

公开核心测试无需游戏资源或模拟器。完整运行还需根据 [assets/README.md](assets/README.md) 准备本地资源：

```powershell
python -m tools.build.check_assets
./tools/build/build_assistant.ps1 -Python ./.venv/Scripts/python.exe
```

构建会生成完整程序到 `dist/Ninja3Assistant/`。先退出正在运行的助手，再构建；不能只替换主 EXE。

安装后也可执行 `ninja3-worker --help` 或 `python -m ninja3_assistant --help` 查看 Worker 参数。开发工具从项目根目录使用 `python -m tools.<分类>.<工具名>` 运行。

## 使用

1. 自行安装 MuMu 和游戏，将所选实例设置为 1280×720 横屏。
2. 构建完成后，双击根目录 `启动助手.cmd`。
3. 在设备页选择实例，在任务中心开启每日清理并勾选项目，也可同时勾选活动和结束方式，然后启动。暂停、继续、停止位于任务页顶部。
4. 默认显示游戏窗口，可通过设备选项控制隐藏。首次修改动作，先在训练所验证。

不要上传包含账号标识、个人信息、配置或未经许可素材的日志和截图。使用时自行了解游戏及模拟器的相关规则。

## 项目结构

| 位置 | 内容 |
| --- | --- |
| `src/ninja3_assistant/` | 按领域分组的 Python 包：调度、实时内核、设备、活动、战斗与入口 |
| `winui/` | WinUI 界面与 Worker 启动 |
| `native_touch/` | C++ 输入执行及协议 |
| `assets/` | OCR 脚本、资源清单；识别素材本地准备 |
| `configs/` | 示例配置；用户实际配置不提交 |
| `tests/` | 与源码领域对应的测试包 |
| `tools/` | 按构建、采集、回放、模型、数据集和诊断分组的工具 |
| `packaging/` | PyInstaller 打包配置 |
| `docs/` | 架构与目录说明 |
| `build/`、`dist/`、`data/` | 本地输出、素材及记录，均不提交 |
