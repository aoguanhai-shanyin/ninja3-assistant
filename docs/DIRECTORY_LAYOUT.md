# 目录规范

公开仓库保留现有平铺 Python 模块，不进行与发布无关的包迁移。架构边界见 `ARCHITECTURE.md`。

- `winui/`：界面源码及通用应用图标；`bin/`、`obj/` 不提交。
- `native_touch/`：C++ 输入源码、构建入口和协议。
- `assets/`：公开 OCR 脚本、资源清单和准备说明；游戏派生图像、模型和元数据仅在本地。
- `configs/`：公开示例及说明；实际设备、账号或模拟器配置不提交。
- `tests/`：全部测试源码；公开核心测试入口不依赖私有素材。
- `tools/`：构建、回放、诊断及数据处理工具；实验工具的数据输入由调用者提供。
- `docs/`：对外架构、功能范围、目录和开发说明。
- `build/`：可再生缓存、打包中间产物与验证日志。
- `dist/Ninja3Assistant/`：本地唯一完整发布包，由根目录启动脚本启动。
- `data/runtime/`：当前运行日志；`data/evidence/`：固定证据；`data/experiments/`：临时或历史实验。

整个 `data/`、本地资源及编译输出都由 Git 忽略。原有素材、录像、诊断和本地历史保留，不随本次源码发布删除或上传。新的验证记录应先选择合适的子目录，不在根目录散放截图或日志。
