# 忍3助手功能清单

按功能逐项实现、验证和更新。朱雀 6.1 的界面可作为功能范围参考；界面上出现的选项不代表其操作流程已经核实。新的识别与操作由本项目独立实现。

## 第一阶段：Windows 助手

- [x] WinUI 3 界面，更名为「忍3助手」。
- [x] 保留逆袭 S：筛选、刷新、持续抢队、准备、结算后继续（完整自动跨局仍待实机观察）。
- [x] 启动、停止、暂停和继续，并按当前画面继续判断。
- [x] 连接检查：验证 MuMu 实例、游戏画面和识别设备，不发送点击。
- [x] 自动扫描 MuMu 多开实例，按名称选择并记住上次选择；展示运行状态、识别频率、点击和结算计数。
- [x] 在复制实例验证 UI 和任务控制；现有流程回归测试通过，原助手保持运行。
- [x] 中断恢复时连接所选实例的 ADB，并使用当前游戏版本可用的启动入口。
- [x] 抢队点击间隔可配置；每次点击后重新识别，暂停或停止可打断连点。
- [x] 正常助手自动识别隼白场景并接管躲避和武器操作，无 Boss 启用开关；已知导航和弹窗优先处理，未知战斗画面等待恢复。
- [ ] 自动启动所选实例并登录进入逆袭悬赏：已实现启动和页面识别，完整冷启动仍待联网实机验证。

## 后续功能：依据朱雀现有界面

以下是已在参考界面中看到的功能名称，具体界面、顺序、识别条件和异常处理仍待采样验证。

- [ ] 日常：饭团回赠、忍者修炼、竞技场结算、忍阶声望、战令奖励、兑换码、喂龙、忍村试炼。
- [ ] 悬赏与挂机：逆袭悬赏、新版悬赏、地区挂机、藏宝图。
- [ ] Boss 与活动：家族 Boss、首领 Boss、师徒 Boss、讨伐鬼族、周末活动。
- [ ] 其他模式：深渊挑战、深渊军团、竞技场、3V3 匹配、家族对战、决胜狭路、备战副本、创意工坊、武道会。
- [ ] 任务组合与执行顺序；单次操作和定时操作。
- [ ] 可配置的中断恢复、异常退出恢复及运行统计。
- [ ] 战斗实验：继续完善禅语魔心攻击识别、轨迹和躲避；验证后再考虑接入主流程。
- [x] 隼白场景引擎：DirectML 固定颜色分割、轨迹与预测躲避、武器就绪检查、暂停/停止、逐帧日志和视频离线回放；正常助手自动调用。
- [x] 独立“场景调试（仅观察）”入口共用场景引擎，只记录识别和建议动作，不发送触控。
- [x] WinUI 离线视频调试：导入本地视频/视频缓存、时间轴定位、源视频逐帧查看、攻击框与轨迹、板子及流程步骤；跳转后局部重新同步，无需模拟器。
- [x] 按所给视频建立全部可核实演示目录，逐项接入 P1–P4 板子参考识别和事件躲避配方；未知/相似板拒识并使用轨迹反馈，执行四跳及空中向下/翻绳/绳下翻滚区分。
- [ ] 隼白实战校准：Boss 选择和进入副本仍手动完成；由用户指导选择 Boss，采样当前忍者与技能按钮，校准跳跃/上下翻和输入延迟；验证跟踪引导、伪 3D 伤害层、板子识别泛化及通关结果，自动通关尚未验证。
