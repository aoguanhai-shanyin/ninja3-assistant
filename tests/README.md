# 验证范围

公开核心测试：

```powershell
python tools/run_portable_tests.py
```

这些测试覆盖任务规划、活动状态机、实时帧与动作计划、取消、策略及模拟输入，不读取游戏素材，不连接模拟器。GitHub Actions 使用相同入口，并编译 C++ 输入组件。

`python -m unittest discover -s tests -q` 是本地完整回归入口。其他测试还需要本地截图、模型与历史 `data/` 数据，未随公开仓库分发。缺少这些数据时，不能把完整回归失败当成核心逻辑回归，也不能宣称完整套件已通过。

当前完整本地套件仍有已知问题：训练所等待超时断言失败；原生延迟指令/循环计数的个别测试受系统调度及采样边界影响，单独复跑可能通过。它们没有通过删断言或放宽阈值处理。避障、绳索登板与稳定上分仍需实机验证。
